复利现值公式：$PV = FV \times (1 + r)^{-n} = FV \times (P/F, r, n)$ ｜ 求未来一笔确定资金折算到现在的真实价值

复利终值公式：$FV = PV \times (1 + r)^n = PV \times (F/P, r, n)$ ｜ 求现在一笔本金若干年后利滚利的本利和总额
普通年金现值公式：$PV = A \times \frac{1 - (1 + r)^{-n}}{r} = A \times (P/A, r, n)$ ｜ 求每年等额收付多期款项折算到现在的一次性总价值
普通年金终值公式：$FV = A \times \frac{(1 + r)^n - 1}{r} = A \times (F/A, r, n)$ ｜ 求每年年末定期定额投入，n 年后连本带利累积总金额
⚖️ 互为倒数关系（机考必考）
• 复利终值系数 与 复利现值系数 互为倒数：$(F/P) \times (P/F) = 1$
• 普通年金终值系数 与 偿债基金系数 互为倒数：$(F/A) \times (A/F) = 1$
• 普通年金现值系数 与 投资回收系数 互为倒数：$(P/A) \times (A/P) = 1$
🔑 15字秒杀口诀：终现互倒年金配，偿债配终收配现。
📅 期初年金（先付年金）转换口诀
期初每一笔款项比期末多滚存 1 期利息，故直接在期末年金基础上乘以 $(1 + r)$：
• 期初终值：$FV_{\text{due}} = A \times [(F/A, r, n+1) - 1]$
• 期初现值：$PV_{\text{due}} = A \times [(P/A, r, n-1) + 1]$
🔑 口诀：期初终值加一减一，期初现值减一加一。
♾️ 永续年金现值直接秒杀
无限期等额支付的年金（如优先股股息、永久奖学金基金）：
• 标准永续年金：$PV = C / r$ （直接拿每年分红除以贴现率）
• 增长型永续年金：$PV = C_1 / (r - g)$ （除以利率与增长率之差）
🔑 口诀：永续年金求现值，年金直接除以收益率。
⚡ 72 法则极速翻倍估算
利用 72 法则无需查表即可心算资产翻倍所需年限：
• 翻倍年限 $n \approx 72 / (r \times 100)$
• 若年收益率为 8%，本金翻倍所需年限为：$72 / 8 = 9$ 年。
• 验证查表：$(F/P, 8\%, 9) = 1.9990 \approx 2.0000$ 倍！
🔑 口诀：本金翻倍用七二，七十二除以收益率。
