# 银行从业备考专属工作流准则 (Bank Exam Workflow)

当用户在当前工作区提出银行从业备考题目、错题疑问或要求解析知识点时，默认执行**“三位一体”备考闭环工作流**，绝不漏掉任何一个认知盲区：

## 阶段一：知识点精析与题眼排除（实时回复交付）
1. **题眼定位与正误剖析**：直击题目核心考核点，清晰说明标准答案的法理/原理依据。
2. **逐项排除解析（为什么不选其他）**：明确指出错误选项的错误根源与出题人设坑套路（概念偷换、反向对调、泛化概念等）。
3. **考点切片横向对比表**：遇相近/易混淆概念必须使用 Markdown 表格进行多维度对比（如：直接融资 vs 间接融资、保险代理人 vs 保险经纪人、分红险 vs 万能险 vs 投连险）。
4. **15字秒杀口诀**：提炼朗朗上口的通俗速记顺口溜，降低考场反应时间。
5. **现行监管与法律标准校准**：全面统一使用 2024~2026 现行规范（国家金融监督管理总局、民法典物权编与合同编、资管新规全面净值化、2025年1月起个人活期纳入M1等）。

## 阶段二：错题账本自动归档 (Mistakes Log)
每次解答错题后，必须在当前对话中自动更新或追加至工作区根目录的：
`错题本_盲区特训账本.md`
- 包含：错题编号（如 MISTAKE-001）、科目、题型、题干与选项、正确答案、盲区解析、速记口诀、录入时间。

## 阶段三：Anki 自动同步注入 (Anki Sync)
每次解答错题后，必须调用本地同步脚本 `sync_mistake_card.py`，将该题目自动同步推送到本地运行的 Anki 中：
- **目标牌组**：`等级考试::银行从业::[错题强化]盲区特训`
- **卡牌模板**：`银行从业·全真机考客观题`
- **标签**：`["2026银行从业", "错题强化", "盲区特训", 题型]`
- **记忆算法**：自动套用 FSRS 科学记忆预设，确保错题在科学复习节点精准唤醒。
